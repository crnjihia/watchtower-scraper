SYSTEM ARCHITECTURE

Differential Data Pipeline

Sequential Scrapy item pipelines ensuring data purity and deterministic change detection.

PIPELINE 100

Validation Pipeline

Rejects any crawled listing missing essential schema attributes: mandatory IDs, source URL, title, company, or e-commerce prices.

PIPELINE 200

Deduplication Pipeline

Calculates SHA-256 content_hash. Drops unchanged duplicates seen within the configurable DEDUP_WINDOW_DAYS (default 3 days).

PIPELINE 300

Pure Diff Engine

Compares incoming item against the database baseline. Produces clean ChangeEvent objects (NEW, PRICE_DROP, UPDATED).

PIPELINE 400

SQLite Persistence

Upserts active items into items table and appends granular field transitions into the history audit table.

Local CLI Execution (Zero Daemon Dependencies)

Run crawls, view metrics, and dry-run alerts directly via Python without needing Docker or Redis:

# 1. Clone repository
git clone https://github.com/crnjihia/watchtower-scraper.git
cd watchtower-scraper

# 2. Install dependencies
pip install -e ".[dev]"

# 3. Run sample crawl
python run.py crawl jobs --limit 5

# 4. View status
python run.py status

Running via GitHub Container Registry (GHCR)

Pull the official pre-built multi-arch image and spin up with Docker Compose:

# Pull latest container package
docker pull ghcr.io/crnjihia/watchtower-scraper:latest

# Run standalone crawl inside container
docker run --rm -v $(pwd)/data:/app/data ghcr.io/crnjihia/watchtower-scraper:latest crawl myjobmag --limit 5

# Or run full background worker & beat scheduler
docker-compose -f docker-compose.ghcr.yml up -d

Extending Watchtower: Adding a New Spider

Create a new Scrapy spider inside angalia/spiders/my_portal.py that yields JobItem or ProductItem:

import scrapy
from angalia.items import JobItem

class MyPortalSpider(scrapy.Spider):
    name = "my_portal"
    allowed_domains = ["example.co.ke"]
    start_urls = ["https://example.co.ke/jobs"]

    def parse(self, response):
        for card in response.css("div.job-item"):
            yield JobItem(
                source="my_portal",
                external_id=card.css("::attr(data-id)").get(),
                url=response.urljoin(card.css("a::attr(href)").get()),
                title=card.css("h2.title::text").get().strip(),
                company=card.css("span.company::text").get().strip(),
            )

SQLite Schema & History Queries

Inspect database records using standard SQL or the Python SQLAlchemy interface:

-- Query top 10 most recent price drops
SELECT h.changed_at, i.source, i.url, h.old_value AS old_price, h.new_value AS new_price
FROM history h
JOIN items i ON i.id = h.item_id
WHERE h.field = 'price' AND CAST(h.new_value AS REAL) < CAST(h.old_value AS REAL)
ORDER BY h.changed_at DESC LIMIT 10;
